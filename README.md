# Memory: DySta 与 VQ-Memory 复现记录

本仓库整理两篇长时序机器人论文的**独立重建代码与实验结果**。结果依据本地留存的运行记录，DySta 更新至 2026-09-02，VQ-Memory 更新至 2026-08-29；此处未重新运行服务器实验。

| 论文 | 当前进度 | 已验证结果 | 尚缺 |
| --- | --- | --- | --- |
| [DySta / SD-VLA](https://arxiv.org/abs/2602.03983) | OpenVLA-7B + DySta 在标准 LIBERO 四套任务完成双卡 15,000 步训练和闭环评测 | Spatial 484/500 (96.8%)；Object 480/500 (96.0%)；Goal 477/500 (95.4%)；Long 339/500 (67.8%)；合计 1780/2000 (89.0%) | 同配置无 DySta 基线、跨动作查询的完整 KV cache 加速、CogACT/SimplerEnv、LIBERO-Memory 与真实机器人实验 |
| [VQ-Memory / RuleSafe](https://arxiv.org/abs/2603.09513) | 按论文重建规则、演示数据、VQ tokenizer、记忆条件和 DP3 短训链路 | 20 条规则 × 50 条演示；256 项码本聚为 4 类；1024 点 DP3 数据；GPU7 上 tokenizer 与 DP3 各 50 步短训 | 作者原始 RuleSafe 资产/轨迹、论文规模训练、同口径闭环 SR/PS 和多种 VLA 对照 |

**准确表述：** DySta 的标准 LIBERO 训练与评测链路已完成，Long 与论文总体结果仍有明显差距。VQ-Memory 当前是工程复现与短训验证，不能把短训损失或规则生成成功率当作论文的机器人闭环成功率。

## 仓库结构

- [DySta 结果](docs/DySta_复现结果.md)：配置、评测协议、数值、限制。
- [VQ-Memory 结果](docs/VQ-Memory_复现结果.md)：数据与模型链路、已有证据、待完成实验。
- [dysta/](dysta/)：独立 DySta 模块、训练/评测脚本、配置和测试的本地快照。
- [vq-memory/](vq-memory/)：VQ tokenizer、RuleSafe 规则、数据生成、配置和测试的本地快照。

本仓库未包含第三方仓库、预训练权重、仿真资产、RLDS/Zarr 数据或大型检查点。DySta 对 OpenVLA-OFT 的本地集成修改及 VQ-Memory 对 DP3 的修改可能仍需按文档接入，仓库代码不能视为无需外部依赖即可一键复跑的完整发布包。

## 复现原则

1. 先锁定论文版本、上游仓库提交、基础模型和数据 revision。
2. 对实现中的论文明确参数与重建假设分别记录。
3. 先做单元测试、一步训练和仿真冒烟，再做正式训练与闭环评测。
4. 每项成功率注明任务数、回合数和严格汇总方式；没有完成的指标留空，不用训练 loss 替代。

详细背景和操作记录保存在原工作区的中文 README。本仓库只发布可公开核查的源码与摘要，涉及服务器路径的示例需要按实际环境修改。
